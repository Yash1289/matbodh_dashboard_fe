Seat attribute as a selector

The rule: when the first field of a crossed cut describes the seat (a zone, an AC, the incumbent MLA's party), the card shows it as a selector, and the table shows the remaining fields for the chosen seat group. The calculation is the same crossed one; choosing another value is display only and never re-runs the engine. The numbers below are placeholders to show layout, not engine output.

1. party_zone × gender

One zone at a time. The selector sits first in the control strip, stronger than the other chips because it decides which seats the table is about. The arrows step through zones without opening the list.

3. In the Configure panel

The cut builder tells you the rule as you build the cut, so the card's result is not a surprise. The seat field is tinted; a respondent field is not. If the seat field is not first, or is alone, there is no hint, because then it is an ordinary row or column field.
