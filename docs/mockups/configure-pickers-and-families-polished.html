Configure: pickers and the other families

The dropdowns behind the Configure fields, and the panels for the families not drawn before. The panels reuse the layout already approved: primary fields first, the rest under More options, conditions deciding what appears, Apply only when valid. Field names, choices and conditions come from configure_families.json and the options code. Question names show a friendly name with the engine id beside it; today the backend returns only the id, so a label source is needed.

1. Pickers

Every picker has the same shape: a field showing the current choice, a list under it, search when the list is long, grey rows with the reason when an option is unavailable, and one control style (radio for one, check box for several).
