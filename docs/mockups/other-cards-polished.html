Other card families, same visual system

Seat ranking, demographic ranking, seat benchmark and relationship, drawn in the style agreed for the grid card: tabs for the main reading of the card, chips for choices, a changed-from-default tint, and a View menu for the rest. Numbers come from the test fixtures (Uttar Pradesh, anchor R2); the one exception is noted under the ranking card. Mock-up only, nothing is built. Tabs, collapsible groups and the cut selector are clickable.

Seat ranking

The current card is a 100-row list with wide empty gaps. Here rank is a badge (top three tinted), the seat name carries its AC number beside it, and the value gets a proportional bar so the spread is visible at a glance.

Seat benchmark

The five engine tables become tabs. In Summary, parties are the columns and the rows are All seats followed by the zones. Each cell merges vote share and seats: value, arrow and change. The reference year is stated once in the chip, not repeated in every cell. The reference ("2022 VS") is a visible chip, changed because it is not "no reference". Each zone is one row, so 16 zones are 16 rows rather than 16 separate tables.
