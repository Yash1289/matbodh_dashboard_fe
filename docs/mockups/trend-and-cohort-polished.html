Trend mode and Make cohort

Two things the earlier pages left open. First, how a ranking card shows rank in each round (up to four). Second, the Make cohort flow on seat ranking and seat benchmark cards, as the seat-cohort spec describes it: pick a rule on the card, preview the seats, then use them as the cohort for the whole dashboard. Numbers are from the test fixtures except where a page says placeholder.

1. Seat ranking in trend mode

Each round is a column. A cell holds the rank badge, the value, and how far the seat moved since the previous round. The first round has no movement, because there is nothing before it. This is the fixture's data: its two rounds share the same figures, so nothing moves, and Seat 128 has no valid result in R1, so it shows "Not ranked" and then "new".

2. Make cohort

The action sits in the card's menu on every seat ranking and seat benchmark card. Demographic ranking cards do not offer it, because the engine cannot return a seat list from them.

Step 1: choose the rule (seat ranking)

The source is the card's own settings, shown read-only, so the user does not re-enter it. Only the rule is chosen here. The rule on a ranking card is "rank is at most N". Seats tied at the cut-off are included.

Step 2: preview, then confirm

The user sees how many seats matched and a short list, then confirms in a separate step. The list is held in this browser session and is not stored on the server. A rule that matches nothing cannot be used.

Step 3: the cohort tab

Using the cohort opens a new dashboard tab, filtered to those seats. The context bar shows the cohort name, its seat count and when it was made, with a way to clear it. The first card is the overall vote share for the cohort. It is drawn here while it runs; figures appear when the run finishes.
